Behavioral pattern

Memento

Memento cho phép một đối tượng tự chụp lại trạng thái của mình thành một bản lưu kín, để sau này quay về đúng trạng thái đó. Nơi cất giữ các bản lưu không cần biết bên trong có gì, nên đối tượng vẫn giữ được các trường riêng của nó.

Bài toán

Hãy hình dung trang quản trị của một cửa hàng online, nơi admin chỉnh cấu hình phí giao hàng gồm ba trường. Để dễ so sánh, mỗi bước ta đều tính phí cho cùng một đơn mẫu trị giá 250.000 ₫, giao xa 5 km.

TrườngÝ nghĩaBản v1
basePhí gốc của mỗi đơn15.000 ₫
per_kmPhí cộng thêm cho mỗi km4.000 ₫
free_fromĐơn từ mức này được miễn phí giao hàng300.000 ₫

Trước mỗi lần chỉnh lớn, admin muốn lưu lại một phiên bản. Nếu lần chỉnh sau làm hỏng giá, họ chỉ cần chọn một phiên bản cũ và bấm khôi phục, thay vì phải nhớ rồi gõ lại từng con số.

Khi chưa có Memento

Cách làm thường gặp là để công cụ admin tự đọc các trường của cấu hình rồi chép ra một chỗ khác:

"""Khi chưa có Memento: công cụ admin tự với vào các trường riêng của cấu hình để sao lưu."""
from dataclasses import dataclass


@dataclass(frozen=True)
class Order:
    value: int
    km: int


SAMPLE = Order(250_000, 5)


def vnd(n: int) -> str:
    return f"{n:,}".replace(",", ".")


class PricingConfig:
    def __init__(self, base: int, per_km: int, free_from: int) -> None:
        self._base = base
        self._per_km = per_km
        self._free_from = free_from  # trường này được thêm sau, khi có chương trình miễn phí

    def update(self, base: int, per_km: int, free_from: int) -> None:
        self._base, self._per_km, self._free_from = base, per_km, free_from

    def bulk_update(self, factor: int) -> None:
        self._base *= factor
        self._per_km *= factor
        self._free_from *= factor

    def fee(self, order: Order) -> int:
        if order.value >= self._free_from:
            return 0
        return self._base + order.km * self._per_km

    def row(self) -> str:
        return f"{vnd(self._base):>9}{vnd(self._per_km):>9}{vnd(self._free_from):>13}"


class AdminTool:
    def __init__(self, config: PricingConfig) -> None:
        self.config = config
        self.backups: dict[str, dict[str, int]] = {}

    def backup(self, label: str) -> None:
        # Chép tay từng trường riêng. Đoạn này viết từ trước khi có _free_from, nên quên mất nó.
        self.backups[label] = {"base": self.config._base, "per_km": self.config._per_km}

    def restore(self, label: str) -> None:
        saved = self.backups[label]
        self.config._base = saved["base"]
        self.config._per_km = saved["per_km"]


def show(step: str, config: PricingConfig) -> None:
    print(f"{step:<15}{config.row()}{vnd(config.fee(SAMPLE)):>10} ₫")


if __name__ == "__main__":
    config = PricingConfig(15_000, 4_000, 300_000)
    admin = AdminTool(config)
    print(f"{'Bước':<15}{'Phí gốc':>9}{'Mỗi km':>9}{'Miễn phí từ':>13}{'Đơn mẫu':>12}")

    admin.backup("v1")
    show("lưu v1", config)

    config.update(20_000, 2_500, 500_000)
    admin.backup("v2")
    show("lưu v2", config)

    show("sửa hàng loạt", config)

    admin.restore("v2")
    show("khôi phục v2", config)

// Khi chưa có Memento: công cụ admin tự với vào các trường của cấu hình để sao lưu.
// Chạy: node before.ts

interface Order {
  value: number;
  km: number;
}

const SAMPLE: Order = { value: 250_000, km: 5 };

const vnd = (n: number) => String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ".");

class PricingConfig {
  // Để công cụ admin sao lưu được, các trường đành phải để công khai.
  base: number;
  perKm: number;
  freeFrom: number; // trường này được thêm sau, khi có chương trình miễn phí

  constructor(base: number, perKm: number, freeFrom: number) {
    this.base = base;
    this.perKm = perKm;
    this.freeFrom = freeFrom;
  }

  update(base: number, perKm: number, freeFrom: number): void {
    this.base = base;
    this.perKm = perKm;
    this.freeFrom = freeFrom;
  }

  bulkUpdate(factor: number): void {
    this.base *= factor;
    this.perKm *= factor;
    this.freeFrom *= factor;
  }

  fee(order: Order): number {
    if (order.value >= this.freeFrom) return 0;
    return this.base + order.km * this.perKm;
  }

  row(): string {
    return vnd(this.base).padStart(9) + vnd(this.perKm).padStart(9) + vnd(this.freeFrom).padStart(13);
  }
}

class AdminTool {
  private config: PricingConfig;
  private backups = new Map<string, { base: number; perKm: number }>();

  constructor(config: PricingConfig) {
    this.config = config;
  }

  backup(label: string): void {
    // Chép tay từng trường. Đoạn này viết từ trước khi có freeFrom, nên quên mất nó.
    this.backups.set(label, { base: this.config.base, perKm: this.config.perKm });
  }

  restore(label: string): void {
    const saved = this.backups.get(label)!;
    this.config.base = saved.base;
    this.config.perKm = saved.perKm;
  }
}

function show(step: string, config: PricingConfig): void {
  console.log(step.padEnd(15) + config.row() + vnd(config.fee(SAMPLE)).padStart(10) + " ₫");
}

  • Công cụ sao lưu phải biết hết ruột của cấu hình. Nó với vào từng trường riêng, nên cấu hình không còn tự quyết định được trạng thái của mình gồm những gì.
  • Thêm một trường là phải nhớ sửa ở nơi khác. Đoạn sao lưu được viết từ trước khi có ngưỡng miễn phí, nên sau khi khôi phục, ngưỡng vẫn kẹt ở 5.000.000 ₫ và đơn 600.000 ₫ lẽ ra được miễn phí lại bị tính tiền.
  • Bản sao lưu có thể bị sửa từ bên ngoài. Đó chỉ là một dict hay object thường, ai giữ nó cũng ghi đè được, và khi đó bản lưu không còn đáng tin.

Lời giải

Ta để chính cấu hình, gọi là Originator, tự chụp trạng thái của mình bằng save() và tự khôi phục bằng restore(). Bản chụp mà save() trả về chính là Memento. Bên ngoài chỉ thấy nhãn của nó, còn trạng thái bên trong thì chỉ cấu hình mới mở ra dùng.

Việc cất giữ các bản chụp thuộc về một lớp khác, gọi là Caretaker, ở đây là History. Nó nhận bản chụp, giữ theo nhãn và đưa lại khi được hỏi, nhưng không bao giờ đọc hay sửa bên trong. Bản TypeScript giữ trạng thái trong một WeakMap mà chỉ module của cấu hình truy cập được, nên bản chụp thật sự kín. Python không cấm được việc đọc trường có dấu gạch dưới, nên ta dựa vào quy ước.

memento.pypython3 memento.py
"""Memento: lưu và khôi phục cấu hình phí giao hàng mà không để bên ngoài chạm vào trạng thái bên trong.

Chạy: python3 memento.py
"""
from dataclasses import dataclass


@dataclass(frozen=True)
class Order:
    value: int
    km: int


SAMPLE = Order(250_000, 5)  # đơn mẫu dùng để xem phí thay đổi ra sao


def vnd(n: int) -> str:
    return f"{n:,}".replace(",", ".")


# Memento: bản chụp niêm phong. Bên ngoài chỉ thấy nhãn, còn trạng thái bên trong
# chỉ PricingConfig mới mở ra dùng. Python không cấm được việc đọc _state, nên ta
# giữ quy ước: ngoài PricingConfig, không ai chạm vào nó.
class Snapshot:
    __slots__ = ("label", "_state")

    def __init__(self, label: str, state: tuple[int, int, int]) -> None:
        self.label = label
        self._state = state


# Originator: cấu hình phí giao hàng, tự biết cách chụp lại và khôi phục chính nó.
class PricingConfig:
    def __init__(self, base: int, per_km: int, free_from: int) -> None:
        self._base = base
        self._per_km = per_km
        self._free_from = free_from

    def update(self, base: int, per_km: int, free_from: int) -> None:
        self._base, self._per_km, self._free_from = base, per_km, free_from

    def bulk_update(self, factor: int) -> None:
        # Người gọi truyền 10 với ý "tăng 10%", nhưng hàm lại nhân thẳng mọi trường với 10.
        self._base *= factor
        self._per_km *= factor
        self._free_from *= factor

    def fee(self, order: Order) -> int:
        if order.value >= self._free_from:
            return 0
        return self._base + order.km * self._per_km

    def save(self, label: str) -> Snapshot:
        return Snapshot(label, (self._base, self._per_km, self._free_from))

    def restore(self, snapshot: Snapshot) -> None:
        self._base, self._per_km, self._free_from = snapshot._state

    def row(self) -> str:
        return f"{vnd(self._base):>9}{vnd(self._per_km):>9}{vnd(self._free_from):>13}"


# Caretaker: giữ các bản chụp theo nhãn nhưng không bao giờ mở chúng ra.
class History:
    def __init__(self) -> None:
        self._snapshots: dict[str, Snapshot] = {}

    def keep(self, snapshot: Snapshot) -> None:
        self._snapshots[snapshot.label] = snapshot

    def get(self, label: str) -> Snapshot:
        return self._snapshots[label]

    def labels(self) -> list[str]:
        return list(self._snapshots)


def show(step: str, config: PricingConfig) -> None:
    print(f"{step:<15}{config.row()}{vnd(config.fee(SAMPLE)):>10} ₫")


if __name__ == "__main__":
    config = PricingConfig(15_000, 4_000, 300_000)
    history = History()
    print(f"{'Bước':<15}{'Phí gốc':>9}{'Mỗi km':>9}{'Miễn phí từ':>13}{'Đơn mẫu':>12}")

    history.keep(config.save("v1"))
    show("lưu v1", config)

    config.update(20_000, 2_500, 500_000)
    history.keep(config.save("v2"))
    show("lưu v2", config)

    config.bulk_update(10)
    show("sửa hàng loạt", config)

    config.restore(history.get("v2"))
    show("khôi phục v2", config)

    config.restore(history.get("v1"))
    show("khôi phục v1", config)

    print(f"Đơn {vnd(big.value)} ₫ được miễn phí đúng như v1, phí {vnd(config.fee(big))} ₫.")
    print(f"History đang giữ {len(history.labels())} bản chụp: {', '.join(history.labels())}.")

// Memento: lưu và khôi phục cấu hình phí giao hàng mà không để bên ngoài chạm vào trạng thái bên trong.
// Chạy: node memento.ts   (Node 22.18 trở lên chạy thẳng TypeScript)

interface Order {
  value: number;
  km: number;
}

const SAMPLE: Order = { value: 250_000, km: 5 }; // đơn mẫu dùng để xem phí thay đổi ra sao

const vnd = (n: number) => String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ".");

// Memento: bên ngoài chỉ thấy nhãn của bản chụp.
interface Snapshot {
  readonly label: string;
}

interface State {
  base: number;
  perKm: number;
  freeFrom: number;
}

// Trạng thái của từng bản chụp nằm trong WeakMap này. Chỉ PricingConfig, viết cùng
// module, mới tra được, nên với mọi chỗ khác bản chụp là một hộp niêm phong.
const sealed = new WeakMap<Snapshot, State>();

// Originator: cấu hình phí giao hàng, tự biết cách chụp lại và khôi phục chính nó.
class PricingConfig {
  private base: number;
  private perKm: number;
  private freeFrom: number;

  constructor(base: number, perKm: number, freeFrom: number) {
    this.base = base;
    this.perKm = perKm;
    this.freeFrom = freeFrom;
  }

  update(base: number, perKm: number, freeFrom: number): void {
    this.base = base;
    this.perKm = perKm;
    this.freeFrom = freeFrom;
  }

  bulkUpdate(factor: number): void {
    // Người gọi truyền 10 với ý "tăng 10%", nhưng hàm lại nhân thẳng mọi trường với 10.
    this.base *= factor;
    this.perKm *= factor;
    this.freeFrom *= factor;
  }

  fee(order: Order): number {
    if (order.value >= this.freeFrom) return 0;
    return this.base + order.km * this.perKm;
  }

  save(label: string): Snapshot {
    const snapshot: Snapshot = Object.freeze({ label });
    sealed.set(snapshot, { base: this.base, perKm: this.perKm, freeFrom: this.freeFrom });
    return snapshot;
  }

  restore(snapshot: Snapshot): void {
    const state = sealed.get(snapshot);
    if (!state) throw new Error(`Bản chụp ${snapshot.label} không do cấu hình này tạo ra`);
    this.update(state.base, state.perKm, state.freeFrom);
  }

  row(): string {
    return vnd(this.base).padStart(9) + vnd(this.perKm).padStart(9) + vnd(this.freeFrom).padStart(13);
  }
}

// Caretaker: giữ các bản chụp theo nhãn nhưng không bao giờ mở chúng ra.
class History {
  private snapshots = new Map<string, Snapshot>();

  keep(snapshot: Snapshot): void {
    this.snapshots.set(snapshot.label, snapshot);
  }

  get(label: string): Snapshot {
    const snapshot = this.snapshots.get(label);
    if (!snapshot) throw new Error(`Không có bản chụp ${label}`);
    return snapshot;
  }

  labels(): string[] {
    return [...this.snapshots.keys()];
  }
}

function show(step: string, config: PricingConfig): void {
  console.log(step.padEnd(15) + config.row() + vnd(config.fee(SAMPLE)).padStart(10) + " ₫");
}

const config = new PricingConfig(15_000, 4_000, 300_000);
const history = new History();
console.log("Bước".padEnd(15) + "Phí gốc".padStart(9) + "Mỗi km".padStart(9) + "Miễn phí từ".padStart(13) + "Đơn mẫu".padStart(12));

show("lưu v1", config);

config.update(20_000, 2_500, 500_000);
history.keep(config.save("v2"));
show("lưu v2", config);

show("khôi phục v2", config);

show("khôi phục v1", config);

console.log(`History đang giữ ${history.labels().length} bản chụp: ${history.labels().join(", ")}.`);

Các vai trò

Vai tròTrong hìnhTrong code
OriginatorBàn điều khiển với ba cần gạt có motor, tự ghi và tự đọc hộp nhớPricingConfig
MementoHộp niêm phong ghi phiên bản, không có cửa sổ nhìn vào trongSnapshot
CaretakerNgăn nhớ bốn ô đánh số, chỉ giữ hộp mà không đọc đượcHistory
ClientNút lưu, nút khôi phục và núm chọn ôĐoạn chương trình chính gọi save() và restore()

Khi nào dùng

  • Khi cần lưu phiên bản rồi khôi phục, như cấu hình, bản nháp bài viết hay biểu mẫu nhiều bước, mà không muốn để lộ các trường riêng của đối tượng.
  • Khi cần hoàn tác nhưng thao tác không đảo ngược được dễ dàng, chẳng hạn một lệnh sửa hàng loạt hay một phép biến đổi làm mất thông tin.
  • Khi muốn chạy thử một thay đổi rồi quay lại nếu kết quả không ổn, như thử một chính sách giá trên bản sao trước khi áp dụng thật.

Khi nào không nên

  • Khi trạng thái rất lớn mà lại phải lưu thường xuyên. Mỗi bản chụp là một bản sao trọn vẹn, nên bộ nhớ tăng rất nhanh, và lưu phần chênh lệch hay dùng Command sẽ hợp hơn.
  • Khi trạng thái đã nằm trong cơ sở dữ liệu có sẵn lịch sử phiên bản. Lúc đó cứ dùng bảng lịch sử hay audit log, đừng giữ thêm một bản trong bộ nhớ.
  • Khi đối tượng chỉ có vài trường công khai và không có ràng buộc nào cần giữ kín. Một bản sao đơn giản là đủ.

Dễ nhầm với

  • Command hoàn tác bằng phép ngược, như nhập 50 thì hoàn tác bằng cách xuất 50. Memento hoàn tác bằng cách đặt lại cả trạng thái đã chụp, nên dùng được cả khi không có phép ngược, nhưng tốn bộ nhớ hơn. Hai pattern hay đi cùng nhau, khi mỗi lệnh giữ một bản chụp của trạng thái trước nó.
  • Prototype cũng sao chép đối tượng, nhưng để tạo ra một đối tượng mới dùng độc lập. Bản chụp của Memento không dùng để làm việc, nó chỉ để quay về.
  • Lưu xuống cơ sở dữ liệu thường có lịch sử riêng ở tầng dữ liệu. Memento sống trong bộ nhớ, ngay trong tầng nghiệp vụ, và hợp với các thao tác ngắn hạn như hoàn tác trong một phiên làm việc.

Ghi chú khi triển khai

  • Hãy giữ bản chụp bất biến. Nếu trạng thái có danh sách hay dict lồng bên trong, hãy chép sâu khi chụp, vì nếu không thì sửa cấu hình sau đó sẽ sửa luôn cả bản chụp.
  • Đặt giới hạn số bản chụp. History nên giữ một số bản gần nhất, hoặc bỏ bớt bản cũ theo thời gian, để bộ nhớ không phình ra mãi.
  • Để Originator tự quyết định thứ cần chụp. Khi cấu hình có thêm trường mới, chỉ save() và restore() phải đổi, còn History không cần biết gì.
  • Kiểm tra bản chụp khi khôi phục. Bản TypeScript từ chối một bản chụp không do chính cấu hình tạo ra, để không ai nhét được một trạng thái tự chế vào.

Kiểm tra nhanh

Sáu câu hỏi ngắn để xem bạn đã nắm Memento tới đâu. Chọn một đáp án, lời giải thích sẽ hiện ngay bên dưới.

  1. Câu 1 Một trình soạn biểu mẫu cho người dùng kéo thả nhiều trường và cần nút Hoàn tác, kể cả cho thao tác sắp xếp tự động vốn rất khó viết phép ngược. Cách nào hợp nhất?

    Memento hợp khi thao tác khó đảo ngược, vì ta chỉ cần đặt lại trạng thái đã chụp. Viết phép ngược cho thao tác sắp xếp tự động rất dễ sai, còn để History đọc thẳng các trường thì phá vỡ tính đóng gói của biểu mẫu.

  2. Câu 2 Trong ví dụ cấu hình phí giao hàng, lớp nào đóng vai Caretaker?

    History giữ các bản chụp theo nhãn và đưa lại khi được hỏi, nhưng không đọc bên trong. PricingConfig là Originator, nơi tạo và đọc bản chụp, còn Snapshot chính là Memento.

  3. Câu 3 Sau lệnh sửa hàng loạt, admin khôi phục bản v2. Đơn mẫu trị giá 250.000 ₫, giao xa 5 km, giờ tốn bao nhiêu tiền giao hàng?

    Bản v2 có phí gốc 20.000 ₫ và 2.500 ₫ mỗi km, còn đơn 250.000 ₫ chưa tới ngưỡng miễn phí 500.000 ₫. Vì vậy phí là 20.000 ₫ cộng năm lần 2.500 ₫, tức 32.500 ₫. Con số 325.000 ₫ là phí lúc cấu hình còn đang sai.

  4. Câu 4 Ở bản chưa có Memento, vì sao sau khi khôi phục v1 thì đơn 600.000 ₫ vẫn bị tính 35.000 ₫?

    Công cụ admin với vào từng trường và chỉ chép phí gốc với phí mỗi km, vì đoạn đó được viết từ trước khi có ngưỡng miễn phí. Với Memento, chính cấu hình tự chụp đủ trạng thái của nó, nên thêm trường mới chỉ cần sửa save() và restore().

  5. Câu 5 Memento khác Command ở cách hoàn tác như thế nào?

    Command, như ở bài nhập xuất kho, hoàn tác bằng một thao tác ngược, nên tiết kiệm bộ nhớ nhưng cần viết được phép ngược. Memento chỉ cần đặt lại bản chụp, nên dùng được cả khi không có phép ngược, đổi lại mỗi bản chụp là một bản sao trạng thái.

  6. Câu 6 Cấu hình có thêm một danh sách vùng giao hàng. Khi viết save(), việc nào dễ gây lỗi nhất?

    Nếu bản chụp chỉ giữ tham chiếu tới cùng một danh sách, lần sửa sau sẽ sửa luôn cả bản chụp và việc khôi phục không còn tác dụng. Hãy chép sâu hoặc dùng cấu trúc bất biến khi chụp. Ba lựa chọn còn lại đều là cách làm đúng.

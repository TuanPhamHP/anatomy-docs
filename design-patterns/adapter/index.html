Structural pattern

Adapter

Adapter bọc một đối tượng có interface không khớp để nó dùng được như đúng interface mà hệ thống đang chờ. Hệ thống giữ nguyên; mỗi nguồn lạ chỉ cần thêm một lớp chuyển đổi nhỏ.

Bài toán

Hệ thống đối soát nhận giao dịch chuyển khoản từ ba ngân hàng. Mỗi ngân hàng có SDK riêng, gọi bằng một hàm khác nhau và trả dữ liệu theo kiểu khác nhau:

Ngân hàngHàm của SDKSố tiềnThời điểm
Afetch()amount: 1250000 (số)"2026-10-30 09:12:05"
Bget_statement()creditAmount: "860.000" (chuỗi, dấu chấm)"30/10/2026 10:40"
Clist_txns()txnAmt: "2400000.00" (chuỗi thập phân)1793333100000 (epoch ms)

Còn hệ thống đối soát chỉ muốn làm việc với một kiểu: Transaction(amount, reference, booked_at), số tiền là số nguyên VND, lấy qua một hàm transactions().

Khi chưa có Adapter

Cách làm thường gặp là nhét logic chuyển đổi của mọi ngân hàng vào ngay trong hệ thống đối soát:

"""Khi chưa có Adapter: logic chuyển đổi của mọi ngân hàng nằm ngay trong hệ thống đối soát."""
from datetime import datetime, timedelta, timezone
from decimal import Decimal

VN = timezone(timedelta(hours=7))


def import_rows(bank: str, rows: list[dict]) -> list[dict]:
    result = []
    for row in rows:
        if bank == "A":
            amount = row["amount"]
            reference = row["desc"]
            booked_at = datetime.strptime(row["time"], "%Y-%m-%d %H:%M:%S").replace(tzinfo=VN)
        elif bank == "B":
            amount = int(row["creditAmount"].replace(".", ""))
            reference = row["remark"]
            booked_at = datetime.strptime(row["postingDate"], "%d/%m/%Y %H:%M").replace(tzinfo=VN)
        elif bank == "C":
            amount = int(Decimal(row["txnAmt"]))
            reference = row["narrative"]
            booked_at = datetime.fromtimestamp(row["valueDate"] / 1000, tz=VN)
        else:
            raise ValueError(f"Chưa hỗ trợ ngân hàng {bank}")  # thêm ngân hàng = sửa hàm này
        result.append({"amount": amount, "reference": reference, "booked_at": booked_at})
    return result


def reconcile(statements: dict[str, list[dict]]) -> int:
    total = 0
    for bank, rows in statements.items():
        for item in import_rows(bank, rows):
            total += item["amount"]
    return total

// Khi chưa có Adapter: logic chuyển đổi của mọi ngân hàng nằm ngay trong hệ thống đối soát.
type Row = Record<string, any>;

function importRows(bank: string, rows: Row[]) {
  return rows.map((row) => {
    switch (bank) {
      case "A":
        return { amount: row.amount, reference: row.desc, bookedAt: `${row.time.replace(" ", "T")}+07:00` };
      case "B": {
        const [day, month, rest] = row.postingDate.split("/");
        const [year, clock] = rest.split(" ");
        return { amount: Number(row.creditAmount.replaceAll(".", "")), reference: row.remark, bookedAt: `${year}-${month}-${day}T${clock}:00+07:00` };
      }
      case "C":
        return { amount: Math.round(Number(row.txnAmt)), reference: row.narrative, bookedAt: new Date(row.valueDate).toISOString() };
      default:
        throw new Error(`Chưa hỗ trợ ngân hàng ${bank}`); // thêm ngân hàng = sửa hàm này
    }
  });
}

function reconcile(statements: Record<string, Row[]>): number {
  let total = 0;
  for (const [bank, rows] of Object.entries(statements)) {
    for (const item of importRows(bank, rows)) total += item.amount;
  }
  return total;
}

console.log(reconcile({
  A: [{ amount: 1250000, desc: "TT HD 1023", time: "2026-10-30 09:12:05" }],
  B: [{ creditAmount: "860.000", remark: "TT HD 1024", postingDate: "30/10/2026 10:40" }],
  C: [{ txnAmt: "2400000.00", narrative: "TT HD 1025", valueDate: 1793333100000 }],
}));
  • Thêm ngân hàng là sửa lõi. Mỗi ngân hàng mới là một nhánh elif mới trong hàm đối soát đang chạy ổn.
  • Logic lẫn vào nhau. Hàm phình theo số ngân hàng; sửa cách đọc ngày của B có thể làm hỏng A.
  • Khó test riêng. Muốn test cách đọc dữ liệu của C phải đi qua cả hàm đối soát.
  • Lỗi lộ ra lúc chạy. Tên ngân hàng là chuỗi "A", "B"; gõ nhầm chỉ phát hiện khi có giao dịch thật.

Lời giải

Định nghĩa một interface chung mà đối soát cần (Target). Với mỗi ngân hàng, viết một Adapter: nó giữ client của ngân hàng bên trong, gọi đúng hàm của ngân hàng đó và trả về Transaction chuẩn. Đối soát (Client) chỉ nhận một danh sách nguồn, không biết có bao nhiêu ngân hàng hay chúng trông thế nào.

adapter.pypython3 adapter.py
"""Adapter: đưa giao dịch của nhiều ngân hàng về một interface chung.

Chạy: python3 adapter.py
"""
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
from decimal import Decimal
from typing import Protocol

VN = timezone(timedelta(hours=7))


# Target: dạng dữ liệu và interface mà hệ thống đối soát chờ đợi.
@dataclass(frozen=True)
class Transaction:
    amount: int  # VND, số nguyên
    reference: str
    booked_at: datetime


class TransactionSource(Protocol):
    def transactions(self) -> list[Transaction]: ...


# Adaptee: client của từng ngân hàng. Mình không sửa được code này.
class BankAClient:
    def fetch(self) -> list[dict]:
        return [{"amount": 1250000, "desc": "TT HD 1023", "time": "2026-10-30 09:12:05"}]


class BankBClient:
    def get_statement(self) -> list[dict]:
        return [{"creditAmount": "860.000", "remark": "TT HD 1024", "postingDate": "30/10/2026 10:40"}]


class BankCClient:
    def list_txns(self) -> list[dict]:
        return [{"txnAmt": "2400000.00", "narrative": "TT HD 1025", "valueDate": 1793333100000}]


# Adapter: mỗi ngân hàng một lớp. Lớp nào cũng chỉ làm một việc là chuyển đổi.
class BankAAdapter:
    def __init__(self, client: BankAClient) -> None:
        self._client = client

    def transactions(self) -> list[Transaction]:
        return [
            Transaction(
                amount=row["amount"],
                reference=row["desc"],
                booked_at=datetime.strptime(row["time"], "%Y-%m-%d %H:%M:%S").replace(tzinfo=VN),
            )
            for row in self._client.fetch()
        ]


class BankBAdapter:
    def __init__(self, client: BankBClient) -> None:
        self._client = client

    def transactions(self) -> list[Transaction]:
        return [
            Transaction(
                amount=int(row["creditAmount"].replace(".", "")),  # "860.000" -> 860000
                reference=row["remark"],
                booked_at=datetime.strptime(row["postingDate"], "%d/%m/%Y %H:%M").replace(tzinfo=VN),
            )
            for row in self._client.get_statement()
        ]


class BankCAdapter:
    def __init__(self, client: BankCClient) -> None:
        self._client = client

    def transactions(self) -> list[Transaction]:
        return [
            Transaction(
                amount=int(Decimal(row["txnAmt"])),  # "2400000.00" -> 2400000
                reference=row["narrative"],
                booked_at=datetime.fromtimestamp(row["valueDate"] / 1000, tz=VN),
            )
            for row in self._client.list_txns()
        ]


# Client: hệ thống đối soát. Nó chỉ biết TransactionSource, không biết ngân hàng nào.
class Reconciler:
    def __init__(self, sources: list[TransactionSource]) -> None:
        self._sources = sources

    def all(self) -> list[Transaction]:
        return [t for source in self._sources for t in source.transactions()]

    def total(self) -> int:
        return sum(t.amount for t in self.all())


if __name__ == "__main__":
    reconciler = Reconciler([
        BankAAdapter(BankAClient()),
        BankBAdapter(BankBClient()),
        BankCAdapter(BankCClient()),
    ])
    for t in reconciler.all():
        print(f"{t.amount:>9,} ₫  {t.reference}  {t.booked_at.isoformat()}".replace(",", "."))
    print(f"Tổng: {reconciler.total():,} ₫".replace(",", "."))
adapter.tsnode adapter.ts
// Adapter: đưa giao dịch của nhiều ngân hàng về một interface chung.
// Chạy: node adapter.ts   (Node 22.18 trở lên chạy thẳng TypeScript)

// Target: dạng dữ liệu và interface mà hệ thống đối soát chờ đợi.
interface Transaction {
  amount: number; // VND, số nguyên
  reference: string;
  bookedAt: string; // ISO 8601, giờ Việt Nam
}

interface TransactionSource {
  transactions(): Transaction[];
}

// Adaptee: client của từng ngân hàng. Mình không sửa được code này.
class BankAClient {
  fetch() {
    return [{ amount: 1250000, desc: "TT HD 1023", time: "2026-10-30 09:12:05" }];
  }
}

class BankBClient {
  getStatement() {
    return [{ creditAmount: "860.000", remark: "TT HD 1024", postingDate: "30/10/2026 10:40" }];
  }
}

class BankCClient {
  listTxns() {
    return [{ txnAmt: "2400000.00", narrative: "TT HD 1025", valueDate: 1793333100000 }];
  }
}

const pad = (n: number) => String(n).padStart(2, "0");

// Epoch ms -> ISO giờ Việt Nam (UTC+7), không phụ thuộc múi giờ của máy chạy.
function isoVN(ms: number): string {
  const t = new Date(ms + 7 * 3600 * 1000);
  return `${t.getUTCFullYear()}-${pad(t.getUTCMonth() + 1)}-${pad(t.getUTCDate())}T${pad(t.getUTCHours())}:${pad(t.getUTCMinutes())}:${pad(t.getUTCSeconds())}+07:00`;
}

// Adapter: mỗi ngân hàng một lớp. Lớp nào cũng chỉ làm một việc là chuyển đổi.
class BankAAdapter implements TransactionSource {
  private readonly client: BankAClient;

  constructor(client: BankAClient) {
    this.client = client;
  }

  transactions(): Transaction[] {
    return this.client.fetch().map((row) => ({
      amount: row.amount,
      reference: row.desc,
      bookedAt: `${row.time.replace(" ", "T")}+07:00`,
    }));
  }
}

class BankBAdapter implements TransactionSource {
  private readonly client: BankBClient;

  constructor(client: BankBClient) {
    this.client = client;
  }

  transactions(): Transaction[] {
    return this.client.getStatement().map((row) => {
      const [day, month, rest] = row.postingDate.split("/");
      const [year, clock] = rest.split(" ");
      return {
        amount: Number(row.creditAmount.replaceAll(".", "")), // "860.000" -> 860000
        reference: row.remark,
        bookedAt: `${year}-${month}-${day}T${clock}:00+07:00`,
      };
    });
  }
}

class BankCAdapter implements TransactionSource {
  private readonly client: BankCClient;

  constructor(client: BankCClient) {
    this.client = client;
  }

  transactions(): Transaction[] {
    return this.client.listTxns().map((row) => ({
      amount: Math.round(Number(row.txnAmt)), // "2400000.00" -> 2400000
      reference: row.narrative,
      bookedAt: isoVN(row.valueDate),
    }));
  }
}

// Client: hệ thống đối soát. Nó chỉ biết TransactionSource, không biết ngân hàng nào.
class Reconciler {
  private readonly sources: TransactionSource[];

  constructor(sources: TransactionSource[]) {
    this.sources = sources;
  }

  all(): Transaction[] {
    return this.sources.flatMap((source) => source.transactions());
  }

  total(): number {
    return this.all().reduce((sum, t) => sum + t.amount, 0);
  }
}

const vnd = (n: number) => n.toLocaleString("vi-VN");

const reconciler = new Reconciler([
  new BankAAdapter(new BankAClient()),
  new BankBAdapter(new BankBClient()),
  new BankCAdapter(new BankCClient()),
]);
for (const t of reconciler.all()) {
  console.log(`${vnd(t.amount).padStart(9)} ₫  ${t.reference}  ${t.bookedAt}`);
}
console.log(`Tổng: ${vnd(reconciler.total())} ₫`);

Khi nào dùng

  • Cần dùng một lớp có sẵn (SDK bên thứ ba, thư viện, hệ thống cũ) nhưng interface của nó không khớp với interface hệ thống đang dùng, và bạn không sửa được hoặc không nên sửa lớp đó.
  • Nhiều nguồn làm cùng một việc theo kiểu khác nhau: nhiều cổng thanh toán, nhiều nhà cung cấp GPS, nhiều nơi lưu file (ổ đĩa, S3), nhiều nhà cung cấp SMS hay email.
  • Muốn cô lập phụ thuộc bên ngoài: đổi nhà cung cấp mà không chạm vào nghiệp vụ, hoặc thay bằng bản giả khi test.

Khi nào không nên

  • Chỉ có một nguồn và interface của nó đã đủ dùng: Adapter chỉ thêm một lớp gián tiếp.
  • Bạn sở hữu code ở cả hai phía: sửa thẳng cho khớp thường đơn giản hơn.
  • Việc "chuyển đổi" thực ra là logic nghiệp vụ lớn (gộp, tách, bù dữ liệu): đó là một service riêng, không còn là adapter.

Dễ nhầm với

  • Facade cũng bọc thứ có sẵn, nhưng để gom cả một hệ con phức tạp thành một cửa dễ dùng. Adapter đổi một interface sang đúng interface mà client đã đòi.
  • Decorator giữ nguyên interface và thêm hành vi (cache, log, retry). Adapter đổi interface.
  • Proxy giữ nguyên interface và kiểm soát việc truy cập (tải lười, kiểm quyền, cache).
  • Bridge được thiết kế từ đầu để hai chiều biến đổi độc lập với nhau. Adapter thường được thêm vào sau, để nối hai thứ đã có.

Ghi chú khi triển khai

  • Object adapter (giữ adaptee làm thuộc tính, như ví dụ) linh hoạt hơn class adapter (kế thừa adaptee): dùng được cả khi lớp gốc không cho kế thừa, và dễ thay bằng bản giả khi test.
  • Giữ adapter mỏng: chỉ đổi tên hàm và hình dạng dữ liệu. Quy tắc nghiệp vụ, ví dụ bỏ qua giao dịch dưới 10.000 ₫, thuộc về hệ thống đối soát.
  • Chuẩn hoá đơn vị ngay trong adapter: tiền về số nguyên VND, thời gian về cùng một múi giờ. Lỗi khó tìm nhất thường nằm ở đơn vị và múi giờ.
  • Mỗi adapter test riêng được bằng dữ liệu mẫu của đúng ngân hàng đó.

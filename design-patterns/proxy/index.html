Structural pattern

Proxy

Proxy là một object đứng thay cho object thật, với đúng interface của object thật. Mọi lời gọi đi qua nó trước, nên nó có thể kiểm quyền, trì hoãn việc tạo object tốn kém tới lúc thật sự cần, hay giữ lại kết quả để lần sau khỏi làm lại. Chỗ gọi không cần biết phía sau là proxy.

Bài toán

Hệ thống có một báo cáo thường niên 1.240 trang. Tải nó từ kho lưu trữ mất khoảng 2,4 giây. Chỉ vai trò ke-toan và giam-doc được đọc. Ba lượt đọc lần lượt đến:

LượtNgười đọcVai tròĐược đọc?
1KháchkhachKhông
2Kế toánke-toanCó
3Kế toán (đọc lại)ke-toanCó

Muốn: người không có quyền bị chặn trước khi tốn bất kỳ giây nào, và báo cáo chỉ tải đúng một lần dù được đọc bao nhiêu lần.

Khi chưa có Proxy

Chỗ nào cần báo cáo thì tự tạo nó, rồi tự kiểm quyền:

// Khi chưa có Proxy: chỗ nào đọc báo cáo cũng tự tải báo cáo và tự kiểm quyền.

const clock = { seconds: 0 }; // đồng hồ giả lập: cộng thời gian thay vì chờ thật

function loadFromArchive(year: number): string[] {
  clock.seconds += 2.4; // đọc một file lớn từ kho lưu trữ: khoảng 2,4 s
  return Array.from({ length: 1240 }, (_, i) => `Trang ${i + 1}`);
}

interface User {
  name: string;
  role: string;
}

const groupDots = (n: number) => String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ".");

class AnnualReport {
  static loads = 0;
  readonly year: number;
  readonly pages: string[];

  constructor(year: number) {
    AnnualReport.loads += 1;
    this.year = year;
    this.pages = loadFromArchive(year);
  }

  read(user: User): string {
    return `Báo cáo thường niên ${this.year} (${groupDots(this.pages.length)} trang)`;
  }
}

function viewReport(user: User): string {
  const report = new AnnualReport(2025); // tải ngay, kể cả khi người xem không có quyền
  if (!["ke-toan", "giam-doc"].includes(user.role)) { // chỗ nào đọc báo cáo cũng phải chép lại dòng này
    return "bị từ chối";
  }
  return report.read(user);
}

const seconds = (value: number) => value.toFixed(1).replace(".0", "").replace(".", ",");

const users: User[] = [
  { name: "Khách", role: "khach" },
  { name: "Kế toán", role: "ke-toan" },
  { name: "Kế toán", role: "ke-toan" },
];
for (const user of users) {
  const start = clock.seconds;
  const text = viewReport(user);
  console.log(`${(user.name + ":").padEnd(9)}${text}, đã tải ${AnnualReport.loads} lần, mất ${seconds(clock.seconds - start)} s`);

  • Tải cả khi bị từ chối. Báo cáo được tạo trước khi kiểm quyền, nên lượt của khách vẫn tốn 2,4 giây.
  • Tải lại mỗi lần đọc. Ba lượt đọc là ba lần tải, 7,2 giây, dù báo cáo không đổi.
  • Kiểm quyền bị chép khắp nơi. Mỗi màn hình, mỗi job xuất file đều phải chép lại điều kiện vai trò. Quên ở một chỗ là lộ báo cáo.

Lời giải

Giữ interface chung Subject (Report, có read(user)). Báo cáo thật (RealSubject) vẫn như cũ. Thêm Proxy cùng interface: nó kiểm quyền trước, chỉ tạo báo cáo thật ở lần đọc hợp lệ đầu tiên rồi giữ lại, sau đó chuyển lời gọi sang báo cáo thật. Chỗ gọi (Client) nhận một Report và không biết đó là proxy.

proxy.pypython3 proxy.py
"""Proxy: đứng thay báo cáo thật, kiểm quyền trước và chỉ tải báo cáo khi thật sự cần.

Chạy: python3 proxy.py
"""
from dataclasses import dataclass
from typing import Protocol


class Stopwatch:
    """Đồng hồ giả lập: cộng thời gian thay vì chờ thật, nên số in ra lần nào cũng giống nhau."""

    def __init__(self) -> None:
        self.seconds = 0.0

    def spend(self, seconds: float) -> None:
        self.seconds += seconds


CLOCK = Stopwatch()


def load_from_archive(year: int) -> list[str]:
    CLOCK.spend(2.4)  # thật ra là đọc một file lớn từ kho lưu trữ: khoảng 2,4 s
    return [f"Trang {n}" for n in range(1, 1241)]


@dataclass(frozen=True)
class User:
    name: str
    role: str


# Subject: interface chung mà mọi chỗ gọi dùng.
class Report(Protocol):
    def read(self, user: User) -> str: ...


# Real subject: báo cáo thật. Tạo ra là phải tải ngay, rất tốn.
class AnnualReport:
    loads = 0

    def __init__(self, year: int) -> None:
        AnnualReport.loads += 1
        self.year = year
        self.pages = load_from_archive(year)

    def read(self, user: User) -> str:
        return f"Báo cáo thường niên {self.year} ({len(self.pages):,} trang)".replace(",", ".")


# Proxy: cùng interface với báo cáo thật, đứng chắn phía trước nó.
class ReportProxy:
    ALLOWED = {"ke-toan", "giam-doc"}

    def __init__(self, year: int) -> None:
        self._year = year
        self._report: AnnualReport | None = None  # chưa tải gì cả

    def read(self, user: User) -> str:
        if user.role not in self.ALLOWED:  # kiểm quyền trước mọi việc khác
            raise PermissionError(f"{user.name} không có quyền xem báo cáo")
        if self._report is None:  # chỉ tải ở lần đọc hợp lệ đầu tiên
            self._report = AnnualReport(self._year)
        return self._report.read(user)


def seconds(value: float) -> str:
    return f"{value:.1f}".replace(".0", "").replace(".", ",")


# Client: chỉ biết interface Report, không biết phía sau là proxy hay báo cáo thật.
def show(report: Report, user: User) -> None:
    start = CLOCK.seconds
    try:
        text = report.read(user)
    except PermissionError:
        text = "bị từ chối"
    print(f"{user.name + ':':<9}{text}, đã tải {AnnualReport.loads} lần, mất {seconds(CLOCK.seconds - start)} s")


if __name__ == "__main__":
    report = ReportProxy(2025)
    show(report, User("Khách", "khach"))
    show(report, User("Kế toán", "ke-toan"))
    show(report, User("Kế toán", "ke-toan"))
    print(f"Tổng: tải {AnnualReport.loads} lần, mất {seconds(CLOCK.seconds)} s")

// Proxy: đứng thay báo cáo thật, kiểm quyền trước và chỉ tải báo cáo khi thật sự cần.
// Chạy: node proxy.ts   (Node 22.18 trở lên chạy thẳng TypeScript)

// Đồng hồ giả lập: cộng thời gian thay vì chờ thật, nên số in ra lần nào cũng giống nhau.
const clock = { seconds: 0 };

function loadFromArchive(year: number): string[] {
  clock.seconds += 2.4; // thật ra là đọc một file lớn từ kho lưu trữ: khoảng 2,4 s
  return Array.from({ length: 1240 }, (_, i) => `Trang ${i + 1}`);
}

interface User {
  name: string;
  role: string;
}

// Subject: interface chung mà mọi chỗ gọi dùng.
interface Report {
  read(user: User): string;
}

const groupDots = (n: number) => String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ".");

// Real subject: báo cáo thật. Tạo ra là phải tải ngay, rất tốn.
class AnnualReport implements Report {
  static loads = 0;
  readonly year: number;
  readonly pages: string[];

  constructor(year: number) {
    AnnualReport.loads += 1;
    this.year = year;
    this.pages = loadFromArchive(year);
  }

  read(user: User): string {
    return `Báo cáo thường niên ${this.year} (${groupDots(this.pages.length)} trang)`;
  }
}

class PermissionError extends Error {}

// Proxy: cùng interface với báo cáo thật, đứng chắn phía trước nó.
class ReportProxy implements Report {
  static readonly ALLOWED = new Set(["ke-toan", "giam-doc"]);
  private readonly year: number;
  private report: AnnualReport | null = null; // chưa tải gì cả

  constructor(year: number) {
    this.year = year;
  }

  read(user: User): string {
    if (!ReportProxy.ALLOWED.has(user.role)) { // kiểm quyền trước mọi việc khác
      throw new PermissionError(`${user.name} không có quyền xem báo cáo`);
    }
    if (this.report === null) { // chỉ tải ở lần đọc hợp lệ đầu tiên
      this.report = new AnnualReport(this.year);
    }
    return this.report.read(user);
  }
}

const seconds = (value: number) => value.toFixed(1).replace(".0", "").replace(".", ",");

// Client: chỉ biết interface Report, không biết phía sau là proxy hay báo cáo thật.
function show(report: Report, user: User): void {
  const start = clock.seconds;
  let text: string;
  try {
    text = report.read(user);
  } catch (error) {
    if (!(error instanceof PermissionError)) throw error;
    text = "bị từ chối";
  }
  console.log(`${(user.name + ":").padEnd(9)}${text}, đã tải ${AnnualReport.loads} lần, mất ${seconds(clock.seconds - start)} s`);
}

const report = new ReportProxy(2025);
show(report, { name: "Khách", role: "khach" });
show(report, { name: "Kế toán", role: "ke-toan" });
show(report, { name: "Kế toán", role: "ke-toan" });
console.log(`Tổng: tải ${AnnualReport.loads} lần, mất ${seconds(clock.seconds)} s`);

Khi nào dùng

  • Virtual proxy (tải lười). Object tốn kém khi tạo (file lớn, kết nối, model nặng) nhưng không phải lúc nào cũng được dùng. ORM dùng đúng ý này cho quan hệ tải lười.
  • Protection proxy (kiểm quyền). Cùng một object, mỗi người được làm những việc khác nhau, và bạn muốn kiểm ở một chỗ thay vì ở mọi chỗ gọi.
  • Caching proxy. Kết quả của object thật đắt và ít đổi, như gọi API bên ngoài hay truy vấn báo cáo: proxy trả lại kết quả cũ cho tới khi hết hạn.
  • Remote proxy. Object thật nằm ở service khác. Client gọi như gọi hàm bình thường, proxy lo việc gửi request và đọc response, như các client sinh ra từ gRPC hay OpenAPI.

Khi nào không nên

  • Object thật rẻ và luôn được dùng: tải lười chỉ thêm một tầng gián tiếp và làm lỗi lộ ra muộn hơn.
  • Quyền đã được kiểm ở tầng ngoài (middleware, API gateway) cho mọi đường vào: kiểm thêm ở proxy chỉ là lặp lại.
  • Dữ liệu đổi liên tục mà proxy lại giữ bản cũ: cần tính chuyện hết hạn và làm mới, nếu không người đọc thấy số liệu sai.

Dễ nhầm với

  • Decorator cũng giữ nguyên interface và bọc object khác, nhưng để cộng thêm hành vi; thường do client tự lắp, có thể chồng nhiều lớp. Proxy kiểm soát việc truy cập object thật và thường tự quản lý vòng đời của nó, như trong ví dụ là proxy tự tạo báo cáo.
  • Adapter đổi sang một interface khác. Proxy giữ đúng interface của object thật.
  • Facade đưa ra một interface mới, đơn giản hơn, cho cả một hệ con. Proxy đứng trước đúng một object, với đúng interface của nó.

Ghi chú khi triển khai

  • Kiểm quyền trước khi tạo hay gọi object thật, như ví dụ: lượt bị từ chối không được tốn gì.
  • Proxy tải lười dùng chung giữa nhiều luồng thì phải khoá lúc tạo, nếu không hai lượt đọc đầu tiên đến cùng lúc có thể tải hai lần.
  • Giữ proxy mỏng. Logic nghiệp vụ của báo cáo nằm trong báo cáo, proxy chỉ quyết định có cho gọi tới hay không và khi nào thì tạo.
  • Cho client nhận interface (Report) qua tham số hay DI, đừng để nó tự tạo ReportProxy. Khi đó đổi sang báo cáo thật, hay sang bản giả khi test, không phải sửa client.

Behavioral pattern

Strategy

Strategy tách một việc có nhiều cách làm thành các lớp riêng có chung một interface. Code dùng nó chỉ giữ một strategy và gọi qua interface, nên có thể chọn hoặc đổi cách làm lúc chạy mà không phải sửa chính mình.

Bài toán

Trang thanh toán của một cửa hàng online phải tính phí giao hàng. Cửa hàng dùng nhiều cách tính, tuỳ khu vực, đơn vị vận chuyển hay chương trình khuyến mãi đang chạy:

Cách tínhQuy tắcĐọc từ đơnPhí cho đơn mẫu
Theo cân nặng15.000 ₫ cho kg đầu, thêm 5.000 ₫ mỗi kg sau, phần lẻ tính tròn một kg3,5 kg30.000 ₫
Theo khoảng cáchĐến 5 km 15.000 ₫, đến 15 km 25.000 ₫, xa hơn 35.000 ₫12 km25.000 ₫
Miễn phí từ 300.000 ₫Đơn từ 300.000 ₫ được miễn phí, dưới mức đó đồng giá 20.000 ₫450.000 ₫0 ₫

Đơn mẫu nặng 3,5 kg, giao xa 12 km, tiền hàng 450.000 ₫. Phần còn lại của trang thanh toán (cộng tiền hàng, áp mã giảm giá, tạo đơn) giống nhau với mọi cách tính; chỉ riêng con số phí giao hàng là thay đổi.

Khi chưa có Strategy

Cách làm thường gặp là một chuỗi if/elif theo tên quy tắc, nằm ngay trong code thanh toán:

before.pypython3 before.py
"""Khi chưa có Strategy: mọi cách tính phí giao hàng nằm chung trong hàm thanh toán."""
import math


def shipping_fee(rule: str, order: dict) -> int:
    if rule == "weight":
        return 15000 + max(0, math.ceil(order["weight_kg"] - 1)) * 5000
    elif rule == "distance":
        km = order["distance_km"]
        return 15000 if km <= 5 else 25000 if km <= 15 else 35000
    elif rule == "free_over_300k":
        return 0 if order["subtotal"] >= 300000 else 20000
    else:
        raise ValueError(f"Chưa hỗ trợ cách tính {rule}")  # thêm cách tính = sửa hàm này


def checkout_total(rule: str, order: dict) -> int:
    return order["subtotal"] + shipping_fee(rule, order)


if __name__ == "__main__":
    order = {"weight_kg": 3.5, "distance_km": 12, "subtotal": 450000}
    for rule in ["weight", "distance", "free_over_300k"]:
        print(rule, shipping_fee(rule, order), checkout_total(rule, order))

// Khi chưa có Strategy: mọi cách tính phí giao hàng nằm chung trong hàm thanh toán.
type Order = { weightKg: number; distanceKm: number; subtotal: number };

function shippingFee(rule: string, order: Order): number {
  switch (rule) {
    case "weight":
      return 15000 + Math.max(0, Math.ceil(order.weightKg - 1)) * 5000;
    case "distance":
      return order.distanceKm <= 5 ? 15000 : order.distanceKm <= 15 ? 25000 : 35000;
    case "free_over_300k":
      return order.subtotal >= 300000 ? 0 : 20000;
    default:
      throw new Error(`Chưa hỗ trợ cách tính ${rule}`); // thêm cách tính = sửa hàm này
  }
}

function checkoutTotal(rule: string, order: Order): number {
  return order.subtotal + shippingFee(rule, order);
}

const order = { weightKg: 3.5, distanceKm: 12, subtotal: 450000 };
for (const rule of ["weight", "distance", "free_over_300k"]) {
  console.log(rule, shippingFee(rule, order), checkoutTotal(rule, order));
}
  • Thêm cách tính là sửa lõi. Mỗi chương trình khuyến mãi mới là một nhánh mới trong hàm thanh toán đang chạy ổn.
  • Hàm phình theo số quy tắc. Các quy tắc nằm cạnh nhau, dùng chung biến; sửa bậc giá theo km có thể làm hỏng nhánh khác.
  • Khó test riêng. Muốn kiểm tra quy tắc miễn phí ở đúng 300.000 ₫ phải đi qua cả hàm thanh toán.
  • Lỗi lộ ra lúc chạy. Tên quy tắc là chuỗi; gõ nhầm "free_over_300k" chỉ phát hiện khi có khách đặt hàng.

Lời giải

Định nghĩa một interface chung cho mọi cách tính (Strategy): quote(order) nhận đơn hàng và trả về phí. Mỗi quy tắc là một lớp riêng (Concrete Strategy) tự đọc phần dữ liệu nó cần. Trang thanh toán (Context) giữ một strategy, gọi quote qua interface, và cho phép thay strategy lúc chạy bằng set_strategy.

strategy.pypython3 strategy.py
"""Strategy: mỗi cách tính phí giao hàng là một lớp, trang thanh toán chỉ giữ một cái.

Chạy: python3 strategy.py
"""
import math
from dataclasses import dataclass
from typing import Protocol


@dataclass(frozen=True)
class Order:
    weight_kg: float
    distance_km: float
    subtotal: int  # VND


# Strategy: interface chung của mọi cách tính phí.
class ShippingStrategy(Protocol):
    name: str

    def quote(self, order: Order) -> int: ...


# Concrete strategies: mỗi lớp một quy tắc, không lớp nào biết lớp nào.
class WeightFee:
    name = "Theo cân nặng"

    def quote(self, order: Order) -> int:
        extra_kg = max(0, math.ceil(order.weight_kg - 1))  # phần lẻ tính tròn một kg
        return 15000 + extra_kg * 5000


class DistanceFee:
    name = "Theo khoảng cách"

    def quote(self, order: Order) -> int:
        if order.distance_km <= 5:
            return 15000
        if order.distance_km <= 15:
            return 25000
        return 35000


class FreeOverThreshold:
    name = "Miễn phí từ 300.000 ₫"

    def __init__(self, threshold: int = 300000, flat_fee: int = 20000) -> None:
        self._threshold = threshold
        self._flat_fee = flat_fee

    def quote(self, order: Order) -> int:
        return 0 if order.subtotal >= self._threshold else self._flat_fee


# Context: trang thanh toán. Nó chỉ biết ShippingStrategy, không biết quy tắc nào.
class Checkout:
    def __init__(self, strategy: ShippingStrategy) -> None:
        self._strategy = strategy

    def set_strategy(self, strategy: ShippingStrategy) -> None:
        self._strategy = strategy

    def shipping(self, order: Order) -> int:
        return self._strategy.quote(order)

    def total(self, order: Order) -> int:
        return order.subtotal + self.shipping(order)


def vnd(n: int) -> str:
    return f"{n:,}".replace(",", ".")


if __name__ == "__main__":
    order = Order(weight_kg=3.5, distance_km=12, subtotal=450000)
    checkout = Checkout(WeightFee())
    for strategy in [WeightFee(), DistanceFee(), FreeOverThreshold()]:
        checkout.set_strategy(strategy)  # đổi cách tính lúc chạy, Checkout không đổi
        print(f"{strategy.name:<22} phí {vnd(checkout.shipping(order)):>6} ₫   tổng {vnd(checkout.total(order))} ₫")
strategy.tsnode strategy.ts
// Strategy: mỗi cách tính phí giao hàng là một lớp, trang thanh toán chỉ giữ một cái.
// Chạy: node strategy.ts   (Node 22.18 trở lên chạy thẳng TypeScript)

interface Order {
  weightKg: number;
  distanceKm: number;
  subtotal: number; // VND
}

// Strategy: interface chung của mọi cách tính phí.
interface ShippingStrategy {
  readonly name: string;
  quote(order: Order): number;
}

// Concrete strategies: mỗi lớp một quy tắc, không lớp nào biết lớp nào.
class WeightFee implements ShippingStrategy {
  readonly name = "Theo cân nặng";

  quote(order: Order): number {
    const extraKg = Math.max(0, Math.ceil(order.weightKg - 1)); // phần lẻ tính tròn một kg
    return 15000 + extraKg * 5000;
  }
}

class DistanceFee implements ShippingStrategy {
  readonly name = "Theo khoảng cách";

  quote(order: Order): number {
    if (order.distanceKm <= 5) return 15000;
    if (order.distanceKm <= 15) return 25000;
    return 35000;
  }
}

class FreeOverThreshold implements ShippingStrategy {
  readonly name = "Miễn phí từ 300.000 ₫";
  private readonly threshold: number;
  private readonly flatFee: number;

  constructor(threshold = 300000, flatFee = 20000) {
    this.threshold = threshold;
    this.flatFee = flatFee;
  }

  quote(order: Order): number {
    return order.subtotal >= this.threshold ? 0 : this.flatFee;
  }
}

// Context: trang thanh toán. Nó chỉ biết ShippingStrategy, không biết quy tắc nào.
class Checkout {
  private strategy: ShippingStrategy;

  constructor(strategy: ShippingStrategy) {
    this.strategy = strategy;
  }

  setStrategy(strategy: ShippingStrategy): void {
    this.strategy = strategy;
  }

  shipping(order: Order): number {
    return this.strategy.quote(order);
  }

  total(order: Order): number {
    return order.subtotal + this.shipping(order);
  }
}

const vnd = (n: number) => n.toLocaleString("vi-VN");

const order: Order = { weightKg: 3.5, distanceKm: 12, subtotal: 450000 };
const checkout = new Checkout(new WeightFee());
for (const strategy of [new WeightFee(), new DistanceFee(), new FreeOverThreshold()]) {
  checkout.setStrategy(strategy); // đổi cách tính lúc chạy, Checkout không đổi
  console.log(`${strategy.name.padEnd(22)} phí ${vnd(checkout.shipping(order)).padStart(6)} ₫   tổng ${vnd(checkout.total(order))} ₫`);
}

Vai tròTrong hìnhTrong code

Khi nào dùng

  • Một việc có nhiều cách làm, và cách nào được dùng phụ thuộc cấu hình, khách hàng hay thời điểm: phí giao hàng, cách tính thuế, chính sách giảm giá, cách làm tròn tiền.
  • Cần đổi cách làm lúc chạy mà code gọi không biết: chọn thuật toán nén, cách sắp xếp kết quả tìm kiếm, cách thử lại khi gọi dịch vụ ngoài lỗi.
  • Muốn test từng quy tắc riêng bằng bảng giá trị biên, và thêm quy tắc mới mà không đụng vào code đang chạy.

Khi nào không nên

  • Chỉ có một cách làm và chưa thấy cách thứ hai: một hàm thường là đủ.
  • Các biến thể chỉ khác nhau ở một con số (phí 20.000 hay 25.000): đưa con số vào cấu hình, không cần thêm lớp.
  • Biến thể tự chuyển qua lại theo vòng đời của object (nháp, chờ duyệt, đã duyệt): đó là State.

Dễ nhầm với

  • State có cấu trúc gần như giống hệt. Khác ở chỗ ai đổi: strategy do bên ngoài chọn và các strategy không biết nhau; còn các state tự chuyển sang state tiếp theo khi có sự kiện.
  • Template Method cố định khung thuật toán ở lớp cha và để lớp con thay vài bước, bằng kế thừa. Strategy thay cả thuật toán bằng composition, và đổi được lúc chạy.
  • Command gói một yêu cầu thành object để xếp hàng, chạy sau hoặc hoàn tác. Strategy là cách làm một việc, được gọi ngay khi cần.
  • Factory Method thường đi cùng Strategy: factory đọc cấu hình và trả về strategy phù hợp, để chuỗi if chỉ còn ở đúng một chỗ.

Ghi chú khi triển khai

  • Trong Python và TypeScript, một strategy có thể chỉ là một hàm (Callable[[Order], int] hay (order: Order) => number). Dùng lớp khi strategy có tham số riêng, như ngưỡng và phí đồng giá của FreeOverThreshold.
  • Chọn strategy từ cấu hình bằng một bảng tra ({"weight": WeightFee, ...}) đặt ở một chỗ, thay vì rải if khắp code.
  • Giữ strategy không có trạng thái thì một instance dùng chung được cho mọi request.
  • Interface chung phải đủ cho mọi strategy: ở đây quote nhận cả đơn hàng, để mỗi quy tắc tự đọc cân nặng, quãng đường hay tiền hàng.
  • Test mỗi strategy ở đúng các mốc biên: 1 kg, 5 km, 15 km, 299.999 ₫ và 300.000 ₫.
